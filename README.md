# KYC Consolidado

Interface web criada do zero para guiar clientes no fluxo de Conheça Seu Cliente (KYC), contemplando captura de documentos (frente e verso) e selfie, revisão das imagens e envio para análise. O objetivo do projeto é oferecer uma experiência responsiva, acessível e segura, que funcione tanto com upload local quanto com captura direta da câmera do dispositivo.
